教学平台：ESP32-S3 核心板 · ESP32 智能小车开发板 · ESP32-S3 无人机开发板

代码说明：第 1~3、6 册的教学示例只使用 Espressif 官方组件（driver / esp_wifi / esp_ble / esp_http_server / esp_camera / freertos）；第 4、5 册的实验代码取自配套开发板工程，其中包含课程自研组件（icm20602、PMW3901、spl06001、VL53L0X 等）以及电脑端 Qt 上位机程序。

附录 B　常见故障排查

现象可能原因排查方法
编译通过但板子无反应引脚号错误、未配置方向用万用表测量目标引脚电平
串口打印乱码波特率不一致、时钟源配置错误核对监视器波特率与 uart_config_t 设置
板子反复重启任务中缺少阻塞点导致看门狗超时检查循环内是否有 vTaskDelay
中断服务函数里崩溃重启中断中调用了阻塞接口，或函数未加 IRAM_ATTR中断只做标记，耗时处理交给任务
中断完全没反应忘了 gpio_install_isr_service()，或触发方式填成 GPIO_INTR_DISABLE检查中断安装与 intr_type 配置
I2C 扫描不到设备上拉电阻缺失、地址错误、未共地先用扫描程序逐地址探测
I2C 读回全 0 / 全 F器件未初始化、模式配置错误读取身份寄存器验证通信
SPI 读回异常时钟极性相位错误、片选未生效用逻辑分析仪核对时序
ADC 读数剧烈跳动输入悬空、未滤波、接地不良输入并联电容并增加软件滤波
PWM 无输出未调用 ledc_update_duty 或使能函数检查 ledc_channel_config 返回值
电机不转驱动电源未接、使能引脚无 PWM测量 ENA / ENB 是否有波形
WiFi 连不上频段不符、密码错误、信号弱确认使用 2.4GHz 网络
摄像头取帧失败帧缓冲未归还、分辨率过高检查是否成对调用获取与归还
光流数据不更新表面无纹理、光照不足、镜头脏污更换有纹理的测试平面
气压高度漂移气流扰动、温度变化增加滤波并设置基准值
姿态角持续漂移未做零偏校准、积分离散误差执行静止校准并检查 dt 计算

附录 E　基本功训练清单

本课程以"基本功达标"为教学主线，项目与实验是训练载体。下表列出各项基本功及其训练场合与验收方式。

序号基本功训练场合验收方式
1识读原理图：找出电源、信号、地6.4 节 + 每块开发板的原理图现场指认任一模块的供电与信号走向
2用万用表测量电压、通断与电平6.2 节 + 每次接线后独立判断供电是否正常、线是否接反
3计算限流电阻、分压电阻与基极电阻6.3 节 + LED / 三极管驱动实验手算并在实物上验证电流
4使用逻辑分析仪抓取总线时序7.4 ~ 7.7 节抓一帧 I2C / SPI / UART 波形并对照手册解析
5阅读数据手册：找到量程、寄存器、时序参数各传感器实验从手册中查出指定寄存器的地址与含义
6使用日志与回溯定位故障6.2 节根据 Backtrace 定位到具体代码行
7按"供电 → 总线 → 驱动 → 数据 → 系统"顺序排故全部实验面对故障现象能给出有序排查步骤
8手写外设初始化流程（不看例程）7.1 ~ 7.7 节现场默写 GPIO / UART / I2C 的初始化步骤
9设计一个自定义通信帧格式7.4 节写出帧结构并说明校验方式
10分析任务划分与共享资源保护8.4 节画出任务交互图并说明加锁位置
11计算定时器分频与 PWM 参数7.2 节 + 13.5 节给定频率与分辨率算出 PSC / ARR / CCR
12区分并正确使用两套优先级规则8.4 节 + 13.7 节口述 NVIC 与 FreeRTOS 优先级的差异

基本功达标要求：第 1 ~ 7 项必须全部通过，第 8 ~ 12 项至少通过三项，方可参加综合项目答辩。
