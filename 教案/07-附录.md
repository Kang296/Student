## 附录 B　常见故障排查

| 现象 | 可能原因 | 排查方法 |
| --- | --- | --- |
| 编译通过但板子无反应 | 引脚号错误、未配置方向 | 用万用表测量目标引脚电平 |
| 串口打印乱码 | 波特率不一致、时钟源配置错误 | 核对监视器波特率与 `uart_config_t` 设置 |
| 板子反复重启 | 任务中缺少阻塞点导致看门狗超时 | 检查循环内是否有 `vTaskDelay` |
| 中断服务函数里崩溃重启 | 中断中调用了阻塞接口，或函数未加 `IRAM_ATTR` | 中断只做标记，耗时处理交给任务 |
| 中断完全没反应 | 忘了 `gpio_install_isr_service()`，或触发方式填成 `GPIO_INTR_DISABLE` | 检查中断安装与 `intr_type` 配置 |
| I2C 扫描不到设备 | 上拉电阻缺失、地址错误、未共地 | 先用扫描程序逐地址探测 |
| I2C 读回全 0 / 全 F | 器件未初始化、模式配置错误 | 读取身份寄存器验证通信 |
| SPI 读回异常 | 时钟极性相位错误、片选未生效 | 用逻辑分析仪核对时序 |
| ADC 读数剧烈跳动 | 输入悬空、未滤波、接地不良 | 输入并联电容并增加软件滤波 |
| PWM 无输出 | 未调用 `ledc_update_duty` 或使能函数 | 检查 `ledc_channel_config` 返回值 |
| 电机不转 | 驱动电源未接、使能引脚无 PWM | 测量 ENA / ENB 是否有波形 |
| WiFi 连不上 | 频段不符、密码错误、信号弱 | 确认使用 2.4GHz 网络 |
| 摄像头取帧失败 | 帧缓冲未归还、分辨率过高 | 检查是否成对调用获取与归还 |
| 光流数据不更新 | 表面无纹理、光照不足、镜头脏污 | 更换有纹理的测试平面 |
| 气压高度漂移 | 气流扰动、温度变化 | 增加滤波并设置基准值 |
| 姿态角持续漂移 | 未做零偏校准、积分离散误差 | 执行静止校准并检查 `dt` 计算 |

## 附录 D　元器件符号与封装速查

| 元器件 | 电路符号特征 | 常见封装 | 引脚识别 |
| --- | --- | --- | --- |
| 电阻 | 矩形方块或波浪线 | 0805 / 0603 / 直插 | 无极性 |

| 电容（电解） | 一条直线 + 一条弧线 | 直插圆柱 / 贴片钽电容 | 长脚为正，壳体标"−"为负 |
| 二极管 | 三角形 + 竖线 | 1N4148 / 1N4007 / SS34 | 色环一端为阴极 |
| 发光二极管 | 二极管符号 + 两个箭头 | 0805 / 直插 | 长脚为正 |
| 三极管（NPN） | 三脚，箭头朝外 | S8050 / S9013 | 平面对自己，从左到右 E-B-C |

## 附录 E　基本功训练清单

本课程以"基本功达标"为教学主线，项目与实验是训练载体。下表列出各项基本功及其训练场合与验收方式。

| 序号 | 基本功 | 训练场合 | 验收方式 |
| --- | --- | --- | --- |
| 1 | 识读原理图：找出电源、信号、地 | 6.4 节 + 每块开发板的原理图 | 现场指认任一模块的供电与信号走向 |
| 2 | 用万用表测量电压、通断与电平 | 6.2 节 + 每次接线后 | 独立判断供电是否正常、线是否接反 |
| 3 | 计算限流电阻、分压电阻与基极电阻 | 6.3 节 + LED / 三极管驱动实验 | 手算并在实物上验证电流 |
| 4 | 使用逻辑分析仪抓取总线时序 | 7.4 ~ 7.7 节 | 抓一帧 I2C / SPI / UART 波形并对照手册解析 |
| 5 | 阅读数据手册：找到量程、寄存器、时序参数 | 各传感器实验 | 从手册中查出指定寄存器的地址与含义 |
| 6 | 使用日志与回溯定位故障 | 6.2 节 | 根据 Backtrace 定位到具体代码行 |
| 7 | 按"供电 → 总线 → 驱动 → 数据 → 系统"顺序排故 | 全部实验 | 面对故障现象能给出有序排查步骤 |
| 8 | 手写外设初始化流程（不看例程） | 7.1 ~ 7.7 节 | 现场默写 GPIO / UART / I2C 的初始化步骤 |
| 9 | 设计一个自定义通信帧格式 | 7.4 节 | 写出帧结构并说明校验方式 |
| 10 | 分析任务划分与共享资源保护 | 8.4 节 | 画出任务交互图并说明加锁位置 |
| 11 | 计算定时器分频与 PWM 参数 | 7.2 节 + 13.5 节 | 给定频率与分辨率算出 PSC / ARR / CCR |
| 12 | 区分并正确使用两套优先级规则 | 8.4 节 + 13.7 节 | 口述 NVIC 与 FreeRTOS 优先级的差异 |

**基本功达标要求**：第 1 ~ 7 项必须全部通过，第 8 ~ 12 项至少通过三项，方可参加综合项目答辩。
